# 媒达 V1.2

> 粘贴链接，下载视频。就这么简单。

媒达是一款 Windows 桌面下载工具，支持 **B站、YouTube、抖音、网易云音乐** 等主流平台。视频、音频、抖音图文都能下，画质音质可以自己选。

## 能做什么

- 粘贴 B站、YouTube、抖音、网易云等各种链接，一键下载
- **抖音图文/图集也能下**（V1.2 新增），多张图自动建文件夹
- 画质自己选：4K、1080p、720p、480p，要清晰还是要省空间你说了算
- 音频单独下：无损 FLAC、高品、标准，听歌党福音
- 不用折腾配置：ffmpeg 内置，Cookie 自动从浏览器提取，解压就能用
- 下载进度一目了然，还有趣味提示陪你等

## 怎么用

1. 下载 `媒达-V1.2.zip` 并解压
2. 双击运行 `媒达 V1.2.exe`
3. 粘贴你要下载的链接（视频、音频、图集都行）
4. 选个保存位置
5. 点「开始下载」
6. 弹窗里选画质或音质
7. 等着就好
